## Как показать сайт

Откройте `/login`: быстрый вход кнопками. Организатор — `org@demo.local`, участники — `user1@demo.local` … `user4@demo.local`. Общий демонстрационный пароль: `FairRound2026!`.

- Организатор → «Добавить задачу» → сохранить → «Создать контест» → выбрать задачу → опубликовать.
- Участник 1 → контест → согласие → арена. Для суммы: `a,b=map(int,input().split());print(a+b)`. Отправить и дождаться OK.
- Дуэль: участник 1 создаёт вызов, ссылку открыть в отдельном профиле/инкогнито под участником 2. Оба дают согласие и нажимают готовность.
- Команда: участники 3 и 4 уже в «Две переменные». Оба открывают «Парный зачёт»: взять задачу, посмотреть код напарника, отправить решение, написать в чат.
- Организатор → «Видеоповторы» → Сергей Климов → «К моменту» → проверить целостность → решение. Исторические подозрительные случаи синтетические и подписаны.

Разминка и парный тур доступны минимум 14 дней после запуска сида. При старте API окно продлевается, если осталось меньше трёх дней; отправки сохраняются. Дневное начало скорректировано один раз, далее продление меняет только конец окна. Не переводите часы и не сбрасывайте базу. Время интерфейса — Europe/Samara, подпись САМ.
