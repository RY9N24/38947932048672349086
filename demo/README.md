# Файлы для демонстрации

Все файлы отправлять через арену платформы. Файлы с бесконечным циклом, fork, памятью, сетью и файловой системой не запускать локальным Python.

Для задачи «Сумма двух чисел»: `wa.py` → WA на тесте 2, `ok.py` / `ok.cpp` → OK. `ce.cpp` → CE, `re.py` → RE, `tle.py` → TLE, `mle.py` → MLE. `net.py`, `write_fs.py`, `read_etc_passwd.py` → RE. `fork_bomb.py` → RE или TLE, в зависимости от того, где сработает ограничение.

Для новой задачи «Квадрат числа» из формы организатора использовать `square_ok.py`, а не `ok.py` (он читает два числа).

После небезопасного решения отправить корректное: это показывает восстановление проверки. Между отправками — минимум 5 секунд.
