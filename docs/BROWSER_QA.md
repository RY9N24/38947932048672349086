# Браузерная приёмка

## Playwright

Настоящий Chromium/Chrome, без подмены API в сценариях S1–S6. Тесты нажимают кнопки, заполняют формы и ждут результат сервисов. Отдельные browser contexts дают независимые сессии двух участников. Автоматические проверки прав используют API с cookie участника.

```sh
pnpm exec playwright install chrome ffmpeg
pnpm test:e2e
```

Или `TEST_BASE_URL=https://<стенд> pnpm test:e2e` на Linux; на PowerShell сначала `$env:TEST_BASE_URL='https://<стенд>'`. Приёмка создаёт тестовые аккаунты и контесты — запускать на демонстрационном стенде.

Размеры: 1280×800, 1440×900, 1920×1080, 768×1024, 390×844. Проверяются ширина документа, выход текста из заголовков/кнопок, загрузка реального локального шрифта, ошибки JavaScript и axe WCAG 2.1 AA. Автоматический тест дополняется просмотром PNG вручную. Скриншоты не являются гарантией отсутствия всех UX-проблем.

## Визуальная проверка

Бумага #F3F1EC, поверхности #FBFAF7, текст #141414, линии #D9D5CC. Оранжевый #FF4D00 — одно главное действие и живые статусы. На арене фон #0F1011. IBM Plex подключены локально. Скругление 2 px, строки и таблицы, без карточных сеток, градиентов, декоративных иллюстраций и рекламного hero.

После любого изменения: проверить 390 px, контраст, клавиатуру и фокус, длинные названия, пустой список, ошибку и загрузку. Скрывать важный текст ради отсутствия переполнения нельзя. Таблица может прокручиваться внутри своей области, вся страница — нет.
